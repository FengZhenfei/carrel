# Carrel 0.4.1

English | [中文](https://github.com/FengZhenfei/carrel/blob/v0.4.1/docs/releases/0.4.1.zh-CN.md)

- **Text queries.** An optional retrieval profile ranks vector and keyword matches first. The service then follows graph references, checks each passage against its indexed version, and appends up to six source passages. The response identifies which passages came from graph follow-up.
- **Image queries.** Text and visual hits share the same top-K. When graph exploration is enabled, queries without a document filter can also return up to two subjects and two one-hop neighbors per subject for further exploration.
- **Follow-up evidence.** The search Skill carries document and graph versions and the original time scope into follow-ups. A stale reference returns HTTP 409 so the agent can look up the source again. Image and crop requests honor the same time scope. Follow-up suggestions cover specific questions the answer has left open.

The general benchmarks repeat the 0.4.0 text, image and document-answer tests and separately replay the 0.3.0 retrieval suite. The codebase evaluation compares Haiku’s answers to 24 questions with and without follow-up on 0.4.1. [Full evaluation](https://github.com/FengZhenfei/carrel/blob/v0.4.1/docs/evaluations/retrieval-0.4.1.md)

## Upgrade from 0.4.0

Update to tag `v0.4.1`, refresh the bundled `carrel-search` Skill in your agent, and restart the search service. To enable the text profile used in this evaluation, set `KB_SEARCH_TEXT_DISCOVERY=true` in the search service environment before restarting. It is opt-in. Existing chunks, indexes and graphs can be used directly.
