# Carrel 0.3.0

[Home](../../README.md) · English | [中文](0.3.0.zh-CN.md)

## Changes

- Versioned LinkML schemas with eight upper classes, type inheritance, class/instance distinctions, and scoped entity identity.
- Table row extraction, external identifiers, source references, and current/historical evidence views.
- Automatic label sampling based on corpus coverage and the model's **Max Input**, with a 30% input budget and background task progress.
- Per-library correction files, included in backups and cleaned up with library deletion.
- Schema and graph statistics APIs, optional hosted text reranker model and API Key settings.
- Parallel text/image reranking with independent relevance gates, rank fusion and text fallback.
- Search skill updates for source images, targeted graph lookups, and clearer fact-quality and historical-evidence handling.

## Design choices in this release

- **Types and identity:** Expand the upper classes to eight and express inheritance, identity scope, and class/instance distinctions in LinkML. Together with table row extraction and external identifiers, this gives entity resolution more explicit evidence.
- **Sampling and capacity:** Replace a manually set sample count with automatic sampling that considers corpus size, content diversity, and model capacity. A 30% input budget balances coverage with context cost.
- **Time and corrections:** Current and historical views distinguish successive facts. Corrections belong to a library, survive graph rebuilds, and are removed when the library is deleted, keeping revisions reusable without passing old rules to a new library.

- **Text and images:** Each model judges relevance on its own scale; rank fusion combines the accepted results. Bounded image candidates and parallel scoring keep the existing request budget. The skill uses source images and focused follow-up queries where they help answer the question.

## Upgrade from 0.2

1. Run `app/.venv/bin/kb cleanup backup` and delete existing graphs in the console. Parsed files and RAG indexes remain available.
2. Update the checkout to `v0.3.0` and run `./deploy.sh` with your usual deployment options.
3. On Linux, restart `carrel-web` and `carrel-search` with `systemctl --user restart carrel-web carrel-search`. On other hosts, restart those application processes.
4. Fill in **Max Input** for graph models, extract labels, and rebuild each enabled graph. Existing parsing and chunks are reused.

The graph format changes in 0.3.0. API clients use `uppers` in place of
`parent_types`, `upper` in entity results, and the eight classes `agent`,
`entity`, `part`, `property`, `process`, `event`, `concept`, and `document`.
Select or upload a schema version to change types and relationships. The
bundled search skill includes these changes.
