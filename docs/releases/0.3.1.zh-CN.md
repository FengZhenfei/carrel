# Carrel 0.3.1

[首页](../../README.zh-CN.md) · [English](0.3.1.md) | 中文

本次更新扩展文件格式支持，改善原文保真与来源定位，并优化控制台加载和 macOS iCloud 同步。

## 解析与来源定位

- 新增 R、Jupyter Notebook、RST、Quarto/RMarkdown、TeX/BibTeX、JSONL、TSV、Nextflow/CWL/WDL、Snakefile、Feature、DOT、XSD、日志及可识别无扩展名脚本的静态解析。
- 保留 Notebook 单元格、代码与已保存输出的对应关系，检索结果可追溯到单元格、输出项、文本行和表格行。
- 恢复 PDF 中被误识别为页眉的标题和正文，合并表格的引用保留原始跨页范围。
- 保留 TeX 章节层级和 HTML 模板内容；过滤 Markdown 正文中的 HTML 注释，同时保留代码示例与文档头部元数据。
- 保留独立图片内容，减少生成式图片描述的叠加，并改善“孤立标题”切块提示的准确性。

## 入库与控制台

- 在扫描阶段过滤 Git LFS 占位文件，不计入文件清单、数量和解析队列。补齐原件后正常入库；已入库文件变为占位符时撤下旧索引。
- 修复新启用知识库的配置保存问题，保持已完成标签抽取任务的终态稳定。
- 通过响应压缩、请求超时与恢复机制改善慢连接下的文件清单加载，处理重复请求和切换知识库后的旧响应，收紧移动端导航布局。

## macOS iCloud 同步示例

- 默认维持 64 个待下载文件，下载完成后补充空位；完善超时、重试及下载助手到系统下载工具的回退。
- 中断的同步任务可补发扫描通知，长时间传输持续刷新镜像锁；更新同步脚本时等待原有任务退出。

## 文档

- 新增中英文 [0.3.0 检索测评报告](../evaluations/retrieval-evaluations-0.3.0.zh-CN.md)，说明检索准确率、图谱贡献和并行重排效果，并补齐 README 与检索指南中的链接。

## 从 0.3.0 升级

1. 将代码更新到 `v0.3.1`，按原部署选项运行 `./deploy.sh`。
2. Linux 上执行 `systemctl --user restart carrel-web carrel-search`；其他环境重启对应应用进程。
3. 使用 macOS iCloud 同步示例的用户，更新已安装同步目录中的脚本，保留现有 `sync.env`，再运行 `./install.sh`。

已有文档保留解析结果和缓存。新增支持格式通过增量扫描入库，并沿用各库的图谱设置。需要将解析改进应用到历史文档时，可在控制台对选定文件重新解析。

从 0.2 升级时，先完成 [0.3.0 发版说明](0.3.0.zh-CN.md)中的图谱迁移步骤。
