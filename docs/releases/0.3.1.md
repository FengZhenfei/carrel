# Carrel 0.3.1

[Home](../../README.md) · English | [中文](0.3.1.zh-CN.md)

This release expands file format support and improves source fidelity, console loading, and macOS iCloud synchronization.

## Parsing and source references

- Add static readers for R, Jupyter Notebook, RST, Quarto/RMarkdown, TeX/BibTeX, JSONL, TSV, Nextflow/CWL/WDL, Snakefiles, Feature, DOT, XSD, logs, and recognized extensionless scripts.
- Preserve notebook cells, code and saved outputs together. Carry cell, output, line and row locations through to search results.
- Recover PDF titles and body text misclassified as headers, and retain the original page range of merged tables in citations.
- Preserve TeX section hierarchy and HTML template content. Filter HTML comments from Markdown prose while retaining code examples and front matter.
- Keep standalone image content, avoid stacking generated figure descriptions, and reduce false heading-only chunk warnings.

## Ingestion and console

- Filter Git LFS pointers during scanning so they stay out of file lists, counts and parsing queues. Restored originals enter the normal ingestion flow; existing index entries are withdrawn when a file becomes a pointer.
- Fix saving the configuration of a newly enabled knowledge base and keep completed label-extraction tasks in their final state.
- Improve file-list loading on slow connections with compressed responses, request timeouts and recovery. Prevent duplicate requests and results from a previously selected library, and make mobile navigation more compact.

## macOS iCloud sync example

- Use a default window of 64 pending downloads, refilling slots as downloads finish. Improve timeouts, retries and fallback from the download helper to the system downloader.
- Recover scan notifications after interrupted transfers and refresh mirror locks during long copies. Updating the sync installation waits for existing agents to stop.

## Documentation

- Add the bilingual [0.3.0 retrieval evaluation](../evaluations/retrieval-evaluations-0.3.0.md), covering retrieval accuracy, graph contribution and parallel reranking, with links from the README and retrieval guide.

## Upgrade from 0.3.0

1. Update the checkout to `v0.3.1` and run `./deploy.sh` with your usual deployment options.
2. On Linux, run `systemctl --user restart carrel-web carrel-search`. On other hosts, restart the corresponding application processes.
3. If you use the macOS iCloud sync example, update the scripts in your installed sync folder and rerun `./install.sh`, keeping your existing `sync.env`.

Existing documents retain their parsed results and caches. Newly supported formats enter through incremental scans and follow each library's graph settings. Reparse selected files in the console to apply the parsing improvements to previously indexed documents.

For upgrades from 0.2, first follow the graph migration steps in the [0.3.0 release notes](0.3.0.md).
