# Carrel 0.4.1

[English](https://github.com/FengZhenfei/carrel/blob/v0.4.1/docs/releases/0.4.1.md) | 中文

- **文字查询。** 新增可选的检索配置，先对向量和关键词命中的原文排序，再沿图谱线索核对切块版本，最多补回六段原文。响应中可以区分直接命中和图谱补回的段落。
- **带图查询。** 文字和图片命中共享前 K 个位置。开启图谱探索且未限定具体文档时，响应还可附上最多两个主体，每个主体最多提供两个一跳邻居，供智能体追问。
- **追查证据。** 检索 Skill 沿用来源文档版本、图谱版本和查询时间范围。引用过期会返回 HTTP 409，智能体可重新定位来源。取原图和裁图遵循相同的时间范围。回答后的追问仅保留有线索且正文尚未解答的问题。

通用复测沿用 0.4.0 的文字检索、图片定位和文档问答题，并单列 0.3.0 检索题集的结果。代码库能力专项在 0.4.1 内比较 Haiku 回答 24 道代码题时，首轮检索与按需补查的表现。[完整测评报告](https://github.com/FengZhenfei/carrel/blob/v0.4.1/docs/evaluations/retrieval-0.4.1.zh-CN.md)

## 从 0.4.0 升级

更新到 `v0.4.1`，同步智能体使用的 `carrel-search` Skill，然后重启检索服务。如需启用本次测评的文字检索配置，在重启前设置环境变量 `KB_SEARCH_TEXT_DISCOVERY=true`。此配置默认关闭，可直接复用现有切块、索引和图谱。
