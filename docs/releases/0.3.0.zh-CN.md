# Carrel 0.3.0

[首页](../../README.zh-CN.md) · [English](0.3.0.md) | 中文

## 更新内容

- 版本化 LinkML 模式：八类上层类型、类型继承、类与实例区分、实体身份范围。
- 表格逐行抽取、外部标识、来源追溯，以及现行与历史证据视图。
- 按资料覆盖度和模型“最大输入”自动采样，输入预算为 30%，支持后台抽取与进度恢复。
- 每库独立的更正规则文件，随状态备份保存，随知识库删除清理。
- 新增模式与图谱统计 API；文本重排支持配置公网模型名和 API Key。
- 图文并行重排、独立相关性判断与排名融合，图片评分不可用时回退文本。
- 检索 Skill 支持原图配答、定向图谱补查，并完善事实质量和历史证据的处理。

## 本次设计考量

- **类型与身份**：将上层类型扩展为八类，用 LinkML 表达继承、身份范围和类与实例的区别；结合表格逐行抽取与外部标识，为实体归并提供更明确的依据。
- **采样与容量**：以自动采样替代手工设置固定数量，兼顾资料规模、内容差异和模型容量，用 30% 输入预算平衡覆盖范围与上下文开销。
- **时间与更正**：通过现行和历史视图区分事实的先后变化；更正规则按知识库管理，重建时复用，删除知识库时清理，让修正持续生效并避免新库继承旧规则。

- **图文检索**：让两类模型按各自的尺度判断相关性，再融合通过判断的结果名次；通过图片候选上限和并行打分控制请求开销。Skill 按问题需要使用原图和定向补查，让回答落到具体证据。

## 从 0.2 升级

1. 执行 `app/.venv/bin/kb cleanup backup`，并在控制台删除已有图谱。已解析文件和 RAG 索引继续保留。
2. 将代码更新到 `v0.3.0`，按原部署选项运行 `./deploy.sh`。
3. Linux 上执行 `systemctl --user restart carrel-web carrel-search`；其他环境重启对应应用进程。
4. 补充建图模型的“最大输入”，重新抽取标签并建图，复用已有解析结果和切块。

0.3.0 更新了图谱格式。API 中的 `parent_types` 改为 `uppers`，实体结果使用 `upper`；八类上层类型为 `agent`、`entity`、`part`、`property`、`process`、`event`、`concept`、`document`。类型与关系通过选择或上传模式版本调整。配套检索 Skill 已同步更新。
